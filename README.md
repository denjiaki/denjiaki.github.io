# denjiaki.github.io

Portfolio site for Alef Ramirez. Plain HTML and CSS, served by GitHub Pages.

## Changing a project image

Each project image lives in the `images` folder at 1440 x 900 pixels. To swap one, upload a new file with the same name, for example `images/hestia.jpg`. Other sizes work too; the page crops them to 16:10 from the top.
