# denjiaki.github.io

Portfolio site for Alef Ramirez. Plain HTML and CSS, served by GitHub Pages.

## Adding screenshots

1. Put the image in the `images` folder, for example `images/fleet-guard.png`.
2. In `index.html`, find the matching `SCREENSHOT` comment.
3. Replace the `<div class="shot">` line under it with the `<img>` line shown in the comment.
